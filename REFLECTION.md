## Reflection - Minh Khanh Truong (N01535604)
This project was very meaningful to me because it allowed me to apply the theoretical knowledge I had obtained from the Parallel Programming and Introduction to AI courses to design real-world applications. Specifically, it helped me gain a deeper understanding of building object detection systems using AI inference. Previously, I was familiar with the basic process of training a model and then using it on new data for detection tasks. However, I only recently learned that the term "inference" refers to the process of using a trained AI model to make predictions or decisions on new, unseen data.

Working on this project with the Jetson platform introduced me to a new level of efficiency and real-time processing that can be easily achieved with GPU-accelerated embedded devices. By implementing the Jetson board, I learned how hardware acceleration can significantly reduce latency and boost throughput, which is necessary for real-time object detection applications like autonomous vehicles and surveillance systems. I also became more comfortable working with OpenCV and CUDA.

One of the most important aspects of this project was the ability to design a basic prototype that could process real-time video input and apply a blur filter using parallel programming. We also effectively documented the process using GitHub, which helped maintain collaboration and track changes smoothly. We encountered some challenges in setting up the environment and optimizing the pipeline for performance. Toward the end of the project, we faced some hardware or technical issues that caused the system to stop functioning correctly. Despite our best efforts to restore the last working version, we couldn't fully recover it before the deadline because of the time constraints. But the earlier working version proved that our workflow and approach were working, and with more time, we could complete and refine the solution.

Throughout this project, I realized there are still gaps in my knowledge when it comes to advanced optimization techniques, embedded system design, and using profiling tools to measure performance. I want to gain deeper expertise in model optimization for edge devices, such as using TensorRT or pruning and quantizing models to reduce their size and inference time. If I were to scale this project for a larger or more complex deployment in an industry setting, I would need to develop a stronger grasp of embedded Linux, real-time system constraints, and low-level hardware-software integration.
