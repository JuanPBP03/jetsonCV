## Reflection - Minh Khanh Truong (N01535604)
This project was very important and meaningful to me because it allowed me to apply the theoretical knowledge I had obtained from the Parallel Programming and Introduction to AI courses to design real-world applications. Specifically, it helped me gain a deeper understanding of building object detection systems using AI inference. Previously, I was familiar with the basic process of training a model and then using it on new data for detection tasks. However, I only recently learned that the term "inference" refers to the process of using a trained AI model to make predictions or decisions on new, unseen data.
Working on this project with the Jetson platform introduced me to a new level of efficiency and real-time processing that can be easily achieved with GPU-accelerated embedded devices. By implementing the Jetson board, I learned how hardware acceleration can significantly reduces latency and boost throughput, which is necessary for real-time object detection applications like autonomous vehicles and surveillance systems.
